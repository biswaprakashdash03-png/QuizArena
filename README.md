## 📌 About the Project

QuizArena is a frontend quiz application designed to make testing your knowledge simple and enjoyable.

Choose your quiz, answer questions before time runs out, and try to beat your previous best score.

## ✨ Features

- ⏱️ **15-Second Timer** — Answer questions within the time limit.
- 🏆 **Best Score Tracking** — Save your highest score in the browser.
- 📊 **Quiz Statistics** — Review your quiz performance.
- 🔄 **Play Again** — Restart the quiz whenever you want.
- 📱 **Responsive Design** — Works on desktop and mobile screens.
- 🎨 **Modern Interface** — Clean and user-friendly design.

## 🛠️ Tech Stack

- React
- JavaScript
- Vite
- CSS
- Browser Local Storage

## 💻 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/biswaprakashdash03-png/QuizArena.git
```

**2. Navigate to the project folder**

```bash
cd QuizArena/client
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal.

## 📦 Production Build

```bash
npm run build
```

## 💾 Score Storage

QuizArena uses browser local storage for best-score tracking. Scores are stored locally in the browser and are not shared across different users or devices.
